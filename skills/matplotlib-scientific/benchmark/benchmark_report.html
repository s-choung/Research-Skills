/matplotlib-scientific

Before/After comparison: default matplotlib vs publication-quality figures with the /matplotlib-scientific skill.

Skill Rules Applied
  • Arial font via FontProperties
  • No grid, no bold, no tight_layout()
  • ax.set_position([0.2, 0.2, 0.666, 0.333])
  • Muted color palette (#77AEB3, #E5885D, ...)
  • Legend frameon=False
  • Top/right spines removed
  • SVG output at 300 DPI
  • 5-10% axis padding
