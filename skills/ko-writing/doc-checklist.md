# 한국어 문서 출력 전 점검

한국어로 문서, 리포트, 스펙, PR 본문, 플랜을 쓸 때 출력 직전에 확인한다. 문장 안의 문체는 `ko-writing` 의 ko-prose.md 가 다룬다.

- 실제 데이터 예시가 설명보다 앞에 있나? 예시에 해설 주석을 달았나?
- 제목에 티켓 번호나 구현 용어가 남았나?
- TL;DR 이 퍼센트 나열로 시작하나? 판단 근거 문장이 있나?
- 한 불릿에 주장을 두 개 이상 넣었나?
- 예시에 없는 필드나 구현체 이름을 본문에서 썼나?
- 서술문에 소수점 수치를 그대로 뒀나?
- 발견 경위, 오해 방어, 대안 나열이 남았나?
- 헤딩이 명사구인가? 문의로 들어오는 질문 문장인가? 답이 짧으면 헤딩에 붙였나?
- 못 하는 것을 완곡하게 썼나? 단정하고, 왜 안 하는지 비용을 한 줄 붙였나?
- 케이스를 조합대로 다 나열했나? 결론을 먼저 주장하고 예시를 뒤에 붙이지 않았나?

하나라도 걸리거나 문서 골격을 처음부터 잡아야 하면 `ko-writing` 의 `doc-style.md` 를 읽고 따른다. 규칙 본문, 전/후 대조표, 문서 유형별 골격이 거기 있다.
