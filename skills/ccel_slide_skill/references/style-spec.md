### 알파(투명도) 관례 — 그대로 재현할 것
- 그림자 스트립(패널 뒤 배경 깔개): `#324A88` **alpha 10%** (네이비), `#DCDAB2` **alpha 31%** (골드)
- 반투명 칩(ON 등): `#0F0F70` **alpha 76%**
- 헤더 오렌지 띠: `#FC9828` **alpha 88%**
- 흐릿한 도형 강조: `#C5A86F`/`#DCDAB2` **alpha 40%**, `#000000` **alpha 43%**
- 빨강 X/번개: `#FF0000` **alpha 29%**
- OOXML alpha val = 불투명도 × 1000 (40% → `40000`). CSS는 rgba()로 동일 불투명도.

- HTML 폰트 스택: `'NanumSquare', '나눔스퀘어', 'NanumSquareRound', 'Malgun Gothic', sans-serif` + ExtraBold=`font-weight:800`, Bold=`font-weight:700`. 웹폰트: `https://cdn.jsdelivr.net/gh/moonspam/NanumSquare@2.0/nanumsquare.css`
- PPTX는 latin+ea 모두 같은 typeface 지정 (`나눔스퀘어 ExtraBold` / `나눔스퀘어 Bold`).

## 3. 헤더 밴드 (콘텐츠 슬라이드 공통, z순서 아래→위. 순서 바꾸면 주황선 2개로 보이는 사고남)

1. **오렌지 띠 (맨 아래)**: rect (0, 1.74cm) 폭 전체 × 0.36cm, `#FC9828` alpha 88%. 위의 이미지(h=1.93cm)에 상부가 덮여 **0.17cm 얇은 라인만 노출**됨. HTML: `top:73px; height:6.4px`.
2. **웨이브 이미지 스트립**: `assets/header_band.png` (원본 image4.png의 세로 39.676%~50.582% 크롭). 위치 (0,0), 크기 33.87×1.93cm. HTML: `height:73px; background-size:cover`.
3. **다크 그라데이션 오버레이**: rect (-0.01,-0.70) 33.88×1.96cm (밴드 상부만 덮음, ~1.26cm까지), linear 0°, 좌측 `#3A3939` **불투명**(원본: schemeClr bg2=E7E6E6 + lumMod 25%) → 우측 `black@59%`, scaled=0. 이미지의 밝은 물결을 어둡게 누르는 역할. HTML: `height:47.6px; linear-gradient(90deg, #3A3939, rgba(0,0,0,.59))`.
4. **제목 텍스트**: (0.80, 0.50) 31.89×1.02cm. 28pt ExtraBold 흰색. 부제는 같은 문단에 ` - 부제` 22pt 런으로 이어붙임.
5. **페이지 번호**: (30.57, 0.81) 3.05×1.01cm, 우상단, `N/전체` 흰색 12~14pt. 원본은 ` (계획서 Np)` 꼬리표 옵션.

## 4. 패널 시스템 (콘텐츠의 기본 골격)

### 4-1. 메인 패널 (탭 칩 + 컨테이너)
- **그림자 스트립**: 컨테이너와 같은 x/폭, 위쪽 ~3cm 높이, `#324A88@10%`(네이비) / `#DCDAB2@31%`(골드). 컨테이너 **뒤**에 깔림.
- **컨테이너**: roundRect **adj=6386** (살짝 둥근 모서리, 반경비 6.4%), fill 흰색 또는 noFill, 테두리 **2.25pt** 섹션색.
- **탭 칩**: roundRect **adj=39062** (많이 둥긂, 반경비 39%), 섹션색 솔리드, 테두리 없음. 컨테이너 상단 모서리에 **겹쳐서** 배치(칩 세로중심 ≈ 컨테이너 top). 크기 ~10~11×1.3~1.4cm. 내부 20pt ExtraBold 흰색, 가운데 정렬.
- 섹션색: 네이비 `#0F0F70` / 골드 `#C5A86F` / 그레이 `#888888` / 오렌지 `#FA9028`.

### 4-2. 내부 카드
- roundRect **adj=12808** (중간 라운드), noFill, 테두리 0.75~1pt `#626DAE`(네이비 계열) 또는 `#D5C097`(골드 계열) 또는 1.5pt `#475DA3`.
- 카드 좌측에 아이콘 + 세로 구분선(1.5pt 흰색 또는 섹션색) + 18pt ExtraBold 소제목 + 16pt Bold 본문 패턴.

### 4-3. 칩/배지
- 작은 칩: roundRect adj=39062, 섹션색 솔리드, 흰색 16pt ExtraBold. (예: "에너지 효율 향상", "반응 장벽 저감" — 오렌지 `#FC9828`)
- 알약 배지: roundRect adj=45805~50000, `#475DA3` 솔리드, 18pt ExtraBold 흰색.
- 상태 칩(ON/OFF): 0.8×0.45cm rect, ON=`#0F0F70@76%`+흰글씨, OFF=`#E7E6E6`+검정. 11pt ExtraBold.

### 4-4. 그라데이션 카드 (시대적 필요성 류)
- roundRect adj=6386, 테두리 2.25pt 섹션색, fill: 세로(270°) 그라데이션
  - 오렌지 계열: 상단 `#FDC88F` → `#FEE4C7` → 하단 흰색
  - 네이비 계열: 상단 `#8787B8` → `#C3C3DC` → 하단 흰색

### 4-5. 요약 밴드 (슬라이드 하단 결론)
- **골드 박스형**: roundRect **adj=23741**, 흰색 fill, 테두리 2.25pt `#C5A86F`, 중앙정렬 18pt (Bold 본문 + ExtraBold 강조 런).
- **네이비 푸터형**: 슬라이드 최하단 full-width rect (높이 2.47cm), `#0F0F70` 솔리드, 20pt 흰색 본문 + `#FA901E` ExtraBold 강조 런.

## 5. 도형 어휘

- 화살표: rightArrow/downArrow, fill은 오렌지 그라데이션 `[#FA901E ↔ #FCC88E]` 또는 네이비 그라데이션 `[흰색→#475DA3]`.
- 흐름 강조: trapezoid/triangle에 그라데이션 (`#0F0F70→#888888` 등), 테두리 없음.
- 선 굵기 관례: 0.5pt(보조), 0.75pt(내부 카드), 1pt, 1.5pt(카드 테두리/구분선), 2pt~2.25pt(패널 테두리/축), 4.75pt(프리폼 곡선).
- 라운드 사각 외 곡률 어휘: adj=6386(컨테이너) < 12808(카드) < 23741(요약밴드) < 39062(칩) < 50000(알약).

## 6. 특수 슬라이드

### 타이틀 슬라이드
- 풀블리드 다크 배경 (`assets/wave_bg.jpg` 또는 코스믹 이미지), 텍스트는 전부 왼쪽 정렬 column (x=2.16cm).

## 7. 애니메이션 (fade) — HTML·PPTX 동일 스펙

원본 덱에는 애니메이션이 없으나 이 스킬의 **고정 요구사항**:

| 항목 | 값 |
|---|---|
| 슬라이드 전환 | **fade**, 700ms |
| 요소 등장 | **fade-in**, 500ms |
| 등장 순서 | 헤더는 즉시, 콘텐츠 블록은 읽기 순서(좌→우, 상→하) |
| stagger | 블록 간 300ms |
| 트리거 | 슬라이드 표시 직후 자동 시작 (클릭 불필요) |

- **PPTX**: `<p:transition spd="slow"><p:fade/></p:transition>` + timing tree(mainSeq 1개 그룹, 모든 효과 `presetID=10 presetClass=entr`(Fade), `transition="in" filter="fade"`, dur=500, i번째 delay=i×300, 자동 시작). 생성은 `scripts/ccel_pptx.py`의 `add_fade_animation()`이 담당 — 직접 XML 쓰지 말 것.
- **HTML**: 슬라이드 전환 `opacity 0.7s`, 블록 `.fade-block` `opacity 0.5s` + `transition-delay: i*0.3s`. 슬라이드 활성화 시 `.visible` 부여.

## 8. 레이아웃 불변 규칙

1. 콘텐츠 영역: 헤더 아래 y≈2.3cm부터 시작, 좌우 마진 0.6~0.9cm.
2. 2단 분할 시 좌우 패널 각 ~15.5cm 폭, 중앙 갭 ~0.7cm. 중앙 세로 구분선: 2.25pt 그라데이션 `[흰→#0F0F70→흰]`.
3. 탭 칩은 반드시 컨테이너 상단에 겹치게 (겹침 = 시그니처. z순서: 그림자 → 컨테이너 → 칩 → 텍스트).
4. 텍스트는 도형 위에 겹쳐 올리는 것이 기본 (별도 텍스트박스, noFill).
5. 페이지 번호는 `현재/전체` 형식 고정.
