/transcript2html

Converts raw YouTube transcript Markdown into a readable Korean dark-mode HTML document with embedded key frame screenshots.

YouTube transcript Markdown를 한국어 dark-mode HTML 문서로 변환하는 skill. 프레임 스크린샷 내장, Stripe 스타일 디자인.

How to Use

사용법

Two commands, two steps. Extract the transcript first, then convert it to a styled HTML document.

명령어 두 개면 끝. 트랜스크립트를 먼저 추출하고, 스타일이 입혀진 HTML 문서로 변환.

Step 1: Extract transcript
Step 1: 트랜스크립트 추출
/youtube https://youtube.com/watch?v=...

Output

Step 2: HTML 변환
/transcript2html output/video_title/
Output
Output

Key Features

핵심 기능

Three capabilities that turn messy auto-captions into a polished reading experience.

어수선한 자동 자막을 제대로 읽을 수 있는 문서로 바꿔주는 세 가지 기능.

Auto-Segmentation
자동 문단 분할

Merges 2-3 word chunks into natural paragraphs. Identifies topic boundaries and generates section headers automatically.

2-3 어절씩 끊긴 자막 조각을 자연스러운 문단으로 합쳐요. 주제가 바뀌는 지점을 찾아서 섹션 제목까지 자동으로 붙여줘요.

Korean Translation
한국어 번역

Natural Korean in polite conversational tone. No translation-ese, no AI slop, no inflated expressions. Technical terms stay in English.

자연스러운 요체 한국어. 번역투 없이, AI 특유의 과장 없이 깔끔하게. 기술 용어는 영어 그대로 유지해요.

Frame Cards
프레임 카드

Key moments from the video embedded with timestamps. Each frame includes a Korean-translated caption of what was being said at that moment.

영상의 핵심 장면을 타임스탬프와 함께 삽입해요. 각 프레임 아래에 그 시점의 대사가 한국어로 번역돼서 붙어요.

How to Use

1. Run /youtube on a YouTube URL to get transcript + frame captures
2. Run /transcript2html on the output folder
3. English transcript gets translated to natural Korean with section headers
4. Frame screenshots are embedded as cards in a dark-mode Stripe-style HTML
