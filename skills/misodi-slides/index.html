misodi-slides

미소디(미래소재디스커버리) 과제 발표자료 스타일을 실측 수치로 박제한 슬라이드 생성 스킬. 어떤 주제를 줘도 HTML과 PPTX가 같은 모습으로, fade 애니메이션까지 똑같이 나온다.

HTML + PPTX 동일 출력 fade 700ms / 500ms·300ms stagger 원본 XML 실측 스펙

이 스킬이 하는 일

원본 미소디 덱 16장을 XML 레벨까지 리버스 엔지니어링해서 스타일 시스템으로 고정했다.

철칙
  • HTML과 PPTX는 같은 레이아웃 · 같은 색 · 같은 텍스트로 항상 둘 다 생성
  • fade 필수 — 슬라이드 전환 700ms + 블록 등장 500ms(300ms stagger), 양쪽 동일
  • 탭 칩이 컨테이너 모서리에 겹치는 레이어링은 시그니처 (z순서: 그림자→컨테이너→칩→텍스트)
  • 알파 · 라운딩은 실측값 고정 — 임의 변경 금지 (references/style-spec.md가 SSOT)

사용법

Claude Code에서 트리거: /misodi-slides · "미소디 스타일로 ~ 만들어줘" · 기존 PPT 첨부 + "이거 미소디 스타일로"

  1. references/style-spec.md를 먼저 읽고 콘텐츠를 패널 단위로 설계 (navy=제안 · gold=성과 · gray=기존 · orange=포인트)
  2. HTML 생성 — templates/deck.html 기반, 등장 블록은 .fade-block, 마지막에 inline_assets.py로 에셋 base64 인라인
  3. PPTX 생성 — misodi_pptx.MisodiDeck 빌더 API, HTML과 같은 좌표(px÷37.795=cm), add_fade_animation()으로 fade 주입
  4. 검증 — soffice 렌더 + 스크린샷 육안 비교, 겹침/overflow 검사, animEffect XML 확인
