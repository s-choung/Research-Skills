# Korean AI Writing Patterns

한국어 AI 출력에서 반복적으로 나타나는 기계적 패턴과 대체 방향.
"이 표현을 쓰지 마라"가 아니라 "이 표현이 나타나면, 원문이 실제로 뭘 말하려 했는지 찾아서 그걸 써라"가 원칙이다.

## 빈 강조 표현

| 패턴 | 문제 | 대체 방향 |
|---|---|---|
| 중요하다 / 핵심적이다 / 필수적이다 | 왜 중요한지를 말하지 않음 | 구체적 결과나 비용을 쓴다. "팀 회의가 중요하다" → "팀 회의를 빼면 같은 기능을 두 명이 따로 만든다" |
| 의미가 있다 / 시사하는 바가 크다 | 무슨 의미인지를 말하지 않음 | 의미를 직접 쓴다. "이 결과는 시사하는 바가 크다" → "이 결과는 기존 가정이 틀렸다는 뜻이다" |
| 효과적인 / 효율적인 | 무엇과 비교해서인지 없음 | 비교 대상이나 측정치를 넣는다. 없으면 삭제한다 |

## 빈 수식어

| 패턴 | 문제 | 대체 방향 |
|---|---|---|
| 다양한 / 여러 가지 / 복합적인 | 구체적 항목을 나열하지 않으려고 쓰는 표현 | 실제 항목을 2~3개 쓰거나, 갯수를 쓴다 |
| 적절한 / 합리적인 / 체계적인 | 기준을 말하지 않음 | 기준을 명시한다. 없으면 삭제한다 |
| 지속적인 / 꾸준한 | 기간이나 빈도 없이 쓰임 | 기간이나 빈도를 넣는다 |

## 관료적 동사 구문

| 패턴 | 문제 | 대체 방향 |
|---|---|---|
| 기여할 수 있다 / 도모한다 / 제고한다 | 행위자와 결과가 모두 없음 | 누가 무엇을 해서 무엇이 바뀌는지 쓴다 |
| 활용하다 / 극대화하다 / 최적화하다 | "쓰다"나 "늘리다"로 충분한 경우가 대부분 | 평이한 동사로 바꾼다 |
| 수립하다 / 도출하다 / 산출하다 | 한문 어투가 필요 없는 맥락에서 격식을 높이려고 쓰임 | 독자와 맥락에 맞는 어투로 낮춘다 |
| ~에 대한 검토가 필요하다 | "검토해야 한다"로 충분 | 주어를 살리고 능동형으로 바꾼다 |

## 구조적 패턴

| 패턴 | 문제 | 대체 방향 |
|---|---|---|
| 현대 사회에서 / 오늘날 / 최근 들어 | 아무 글에나 붙는 도입부 | 첫 문장에 구체적 사건, 주장, 문제를 놓는다 |
| 본 글에서는 ~을 살펴보고자 한다 | 목차를 쓰는 것이지 글을 시작하는 게 아님 | 삭제하고 바로 첫 주장으로 시작한다 |
| 이를 통해 / 이를 바탕으로 / 이를 고려할 때 | 앞 문장과의 논리적 관계를 흐리는 접속 | 실제 인과("~때문에", "~한 결과")나 대조("그런데", "하지만")를 쓴다 |
| 나아가 / 더불어 / 아울러 | 항목을 나열할 때 쓰는 기계적 전환 | 나열이면 나열임을 인정하고 리스트로 쓰거나, 논리적 연결을 쓴다 |
| 종합적으로 / 결론적으로 / 요약하자면 | 방금 한 말을 반복하려는 신호 | 삭제한다. 이미 말한 것은 반복하지 않는다 |

## 어미 패턴

| 패턴 | 문제 | 대체 방향 |
|---|---|---|
| ~할 필요가 있다 | 거의 모든 AI 한국어 출력의 기본 종결 | "~해야 한다" 또는 구체적 행동을 쓴다 |
| ~것으로 판단된다 / ~것으로 보인다 | 행위자를 숨기는 피동 | 누가 판단하는지 밝히거나, 직접 주장한다 |
| ~라고 할 수 있다 | 주장을 회피하는 표현 | 주장이면 주장한다. 불확실하면 불확실한 이유를 쓴다 |

## 한국어 고유의 리듬 문제

- **명사화 과다**: "의사결정의 효율화를 위한 프로세스의 개선이 필요하다" → "더 빨리 결정하려면 프로세스를 고쳐야 한다." 명사+의+명사+의 체인이 3단계 이상이면 풀어 쓴다.
- **균일한 문장 길이**: 영어와 동일한 문제. 한국어에서도 짧은 문장("안 됐다.")과 긴 문장이 섞여야 자연스럽다.
- **과도한 존댓말 균일성**: 모든 문장이 "~습니다"로 끝나면 기계적으로 느껴진다. 문맥에 따라 "~다" 체(서술체)나 "~요" 체를 섞는 것이 자연스러운 경우가 많다. 단, 독자와 문서 유형에 맞춰 판단한다.

## 주의

이 목록의 표현이 항상 나쁜 것은 아니다. "중요하다"가 적절한 문맥은 존재한다. 기준은 "이 표현을 뺐을 때 문장이 잃는 게 있는가"이다. 잃는 게 없으면 빈 표현이다. 잃는 게 있으면 남긴다.
