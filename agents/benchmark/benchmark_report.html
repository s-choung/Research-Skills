Paper Ref-Hunter

Crossref + OpenAlex API 기반 논문 검색 스킬 Academic paper search skill powered by Crossref + OpenAlex APIs

문제 The Problem

LLM에게 참고문헌을 요청하면 DOI가 실존하지 않거나 다른 논문을 가리키는 경우가 대다수다. GPT-4.1-mini 벤치마크에서 8명의 연구자에 대해 40편의 논문을 요청한 결과, 47.5%의 DOI가 가짜였고 제목이 정확히 일치하는 비율은 17.5%에 불과했다. Paper Ref-Hunter는 Crossref와 OpenAlex API를 직접 호출하여 실제 논문만 반환한다. When you ask an LLM for references, most DOIs either don't exist or point to wrong papers. In our GPT-4.1-mini benchmark across 8 researchers and 40 papers, 47.5% of DOIs were fake and only 17.5% of titles matched exactly. Paper Ref-Hunter calls Crossref and OpenAlex APIs directly to return only real papers.

작동 방식 How It Works

HUNT

Crossref API

저자 + 키워드로 특정 논문을 찾는다. "그 Chorkendorff 논문 뭐더라?" 같은 질문에 적합. Find a specific paper by author + keywords. Best for "What was that Chorkendorff paper?"

DISCOVERY

OpenAlex API

주제/키워드로 관련 논문 K편을 인용수 순으로 반환한다. 리뷰나 서론 작성 시 유용. Return K papers ranked by citation count for a topic. Useful for writing reviews or introductions.

Tips

  • 희귀한 성 + 키워드 = 거의 100% 적중. Chorkendorff 4/4, Kitchin 4/4, Mavrikakis 3/4. Rare surname + keywords = near-100% hit rate. Chorkendorff 4/4, Kitchin 4/4, Mavrikakis 3/4.
  • 흔한 성(Li, Zhang, Wang)은 제목의 고유 키워드를 반드시 포함. 그래도 안 되면 DISCOVERY 모드로 전환. Common surnames (Li, Zhang, Wang) require unique title keywords. If still failing, switch to DISCOVERY mode.
  • 주제 탐색은 DISCOVERY 모드(OpenAlex)가 인용수 기반으로 더 정확. 벤치마크 평균 적합률 76%. Topic exploration works better in DISCOVERY mode (OpenAlex) with citation-based ranking. Benchmark avg. relevance: 76%.
  • 논문 쓸 때 /paper-ref topic "your claim"으로 관련 논문 K편을 바로 받을 수 있다. While writing, use /paper-ref topic "your claim" to get K relevant papers instantly.
